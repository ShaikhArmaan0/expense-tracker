# 💰 Expense Tracker

A command-line Expense Tracker built with Python.

## Features

- ✅ Add Expenses
- ✅ List Expenses
- ✅ Update Expenses
- ✅ Delete Expenses
- ✅ Monthly Expense Summary
- ✅ Total Expense Summary
- ✅ Export Expenses to CSV
- ✅ JSON Data Storage
- ✅ Input Validation
- ✅ Multi-file Project Structure

## Project Structure

```
Expense Tracker/
│
├── main.py
├── expense.py
├── reports.py
├── storage.py
├── utils.py
├── expenses.json
├── expenses.csv
└── README.md
```

## Technologies Used

- Python
- JSON
- CSV
- datetime

## How to Run

python main.py
